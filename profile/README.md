### What is Pane?

Pane is a modern helpdesk and ticketing platform you run yourself. It is built to stay out of the way: a quiet glass interface, clear ticket states, and a docs section that lives right next to the queue, so the people asking for help and the people giving it can see what matters.

### Highlights

| | |
| --- | --- |
| **Ticketing** | A focused inbox with clear states: Open, Pending, Urgent and Resolved. |
| **Docs** | A built-in knowledge base, linked straight from tickets. |
| **Roles** | Tiered access for **Admin**, **Agent** and **Doc Writer**. |
| **Glass UI** | A frosted, low-noise interface in light and dark mode. |
| **Self-hosted** | One Docker Compose file. Your data stays on your servers. |

### Quick start

```bash
git clone https://github.com/YOUR-ORG/pane.git
cd pane
docker compose up -d
```
